Multi-agent, multi-robot control.

An LLM-driven task-planning framework for coordinating heterogeneous robot fleets through natural-language instructions.

LangChain ROS 2 Isaac Sim Docker gRPC Python

Overview

Natural language as the planning layer

I led development of a multi-agent architecture that translated high-level instructions into robot-specific actions. LangChain handled LLM integration and tool use, while ROS 2 connected planning to execution across different platforms.

The system was validated with UR5 manipulators, Husky unmanned ground vehicles, and KUKA arms in Isaac Sim, as well as selected hardware environments.

Problem

Coordination did not scale with hard-coded workflows

Traditional multi-robot systems require manual task allocation and custom coordination logic. As platform capabilities and task variations grow, that approach becomes slow to extend and difficult for non-specialists to operate.

The project explored whether an LLM could serve as a high-level planner while deterministic services retained responsibility for robot control and execution.

Contributions

Architecture, integration, and team leadership

  • Architected a LangChain–ROS 2 bridge for task allocation across heterogeneous platforms.
  • Designed a multi-agent coordination flow with capability-aware task assignment.
  • Scaled the work from a two-robot prototype to simulations involving up to seven robots.
  • Migrated simulation work from Gazebo to Isaac Sim.
  • Built modular Docker and gRPC services across perception, planning, and execution.
  • Grew and mentored the engineering team from two to four members.

Approach

A hierarchy between language and control

The LLM operated at the task level: it decomposed a natural-language goal into structured subtasks and allocated them according to robot capability and state. Lower-level services handled execution and returned state to the planning layer.

When a subtask failed, the system could regenerate the plan and reallocate available work. This separation kept the conversational interface flexible while preserving modular control boundaries.

Outcome

A practical foundation for agentic planning

  • Reduced task specification from manual programming workflows to natural-language interaction.
  • Coordinated up to seven robots simultaneously in simulation.
  • Demonstrated the system in controlled and selected real-world scenarios.
  • Established reusable integration patterns for later internal projects.
